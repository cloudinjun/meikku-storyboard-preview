# Reference Asset Audit

Reference: https://github.com/guokaigdg/animal-island-ui/tree/main

Observed source asset structure at review time:

- fonts: 9 bundled WOFF2 files;
- functional icon layer: 16 named UI icons;
- item/object icon library: 488 PNG assets;
- divider graphics: 5 SVG/PNG assets;
- cursor graphics: 2 assets;
- footer/scene graphics: 2 assets;
- demo shell backgrounds, app icons, favicon, and Nook-phone artwork.

Meikku translation: semantic icons, object/role avatars, wallpapers, dividers, cursors, patterns, empty states, loaders, app icons, and a manifest. No Animal Island source image is copied into this repository.
