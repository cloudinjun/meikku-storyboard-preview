# Meikku Official Logo

The human–robot high-five symbol is the official Meikku logo as of 2026-08-12.

## Production files

- `meikku_logo_highfive_slate.svg` — authoritative light-field SVG in Meikku Slate `#232322`.
- `meikku_logo_highfive_paper.svg` — reversed SVG in Meikku Paper `#FCFCFA` for slate or dark fields.
- `meikku_logo_highfive_slate.eps` — vendor interchange artwork in Meikku Slate.
- `meikku_logo_highfive_preview.png` — review preview only; do not use it for production layout.

The SVG viewBox is trimmed to the visible artwork bounds so layout software aligns the mark by its actual silhouette rather than by asymmetric source-canvas whitespace. The supplied path geometry is unchanged.

The submitted source archive remains at `ui/assets/human_robot_highfive_vector_files.zip`.

## Use

- Keep the complete human, robot, meeting hands, and three impact rays intact.
- Scale proportionally and keep clear space equal to one quarter of the mark height on all sides.
- Use the slate or paper version as supplied. Do not split the partners into different colors.
- Minimum mark width: 72 px on screen, 18 mm in print, and 30 mm for embroidery or laser work.
- For smaller placements, use the typeset name `MEIKKU` in Bungee without the symbol.
